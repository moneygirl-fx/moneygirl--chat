# Money Girl Chat

This repository contains the Money Girl chat extension, kept separate from the FOREX Money Girl project.

## Extension files
- `manifest.json`
- `background.js`
- `content.js`
- `styles.css`

## Kiwi Browser
Download this repository as a ZIP, extract it on your phone, and load the extracted folder as an unpacked extension in Kiwi Browser.

## Current backend note
The extension files are uploaded as supplied. The background script may still point to a local backend, so the next step is to move the reply server online and update the extension to use that cloud URL.
